# AI Frontier Navigation

AI Frontier Navigation 第一版是一个静态可打开的 AI 前沿精选导航 MVP。它聚焦“可解释的精选条目导航”，内容由人工维护的结构化数据驱动，用于展示论文、项目、博客、模型平台、评测榜单和外部讨论入口。

## Scope

- 首页展示今天值得看的 AI 前沿来源/论文/项目/博客。
- 支持按主题、来源类型、可信度、更新频率和关键词筛选。
- 条目详情展示原始 URL、推荐理由、可信度解释、更新频率、适合人群和外部讨论入口。
- 第一版不包含登录、自建论坛/论坛功能、评论、审核、爬虫或 AI API；内容更新由人工维护完成。

## Run

直接在浏览器打开 `index.html` 即可运行。

## Lightweight Checks

```bash
node --check app.js
```

再用浏览器桌面和移动端宽度检查 `index.html` 的筛选、空状态、列表选择和详情区域。
