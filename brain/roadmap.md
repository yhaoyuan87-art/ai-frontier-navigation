# Roadmap

## Now

第一阶段目标是把现有静态 AI 信息源导航升级为精美、可信、可解释的 AI 前沿信息入口。

### Batch 1

- 重构条目数据模型，从 source URL 扩展为 curated entry。
- 补充首批精选内容样例，覆盖论文、项目、博客、社区讨论入口和高可信来源。
- 首页增加“今天值得看”区域。
- 支持按主题、来源类型、可信度、更新频率和标签筛选。
- 增加条目详情视图，展示 URL、推荐理由、可信度解释、更新频率、适合人群和外部讨论链接。
- 升级视觉设计为高密度、精致、可信的信息工作台。
- 完成桌面和移动端基础适配。
- 保持静态直接打开运行。

## Next

第二阶段在不引入自建社区的前提下，提高内容维护质量和探索效率。

- 将数据从 app.js 拆分到独立 data.js 或 sources.js。
- 增加编辑收录规则文档。
- 增加可信度评分规则说明。
- 增加精选主题集合，例如 Agent、RAG、多模态、开源模型、评测、安全、AI 产品化。
- 增加按难度或适合人群筛选。
- 增加最近更新排序和精选排序。
- 增加外部讨论平台标识。
- 改善键盘导航和可访问性细节。
- 为内容维护者提供数据字段模板。

## Later

后续只有在内容规模、用户使用和维护需求被验证后再考虑扩大架构。

- 引入静态构建链或轻量框架。
- 引入可维护的内容管理流程。
- 增加用户本地收藏或本地阅读状态。
- 增加订阅源导出或 newsletter 形态。
- 增加轻量分析以了解用户点击和筛选偏好。
- 在有真实社区需求后，再评估登录、评论和审核系统。
- 在内容维护成本过高后，再评估爬虫或 AI 辅助摘要。

## Explicitly Deferred

- 自建论坛。
- 登录注册。
- 发帖评论。
- 审核后台。
- 反垃圾系统。
- AI API 自动总结。
- 自动爬虫。
- 数据库。
- 复杂服务端架构。
